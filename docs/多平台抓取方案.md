## 一、广西人才网 (gxrc.com) — ✅ 已打通

```bash
# 搜索
browser-act --session jh browser open chrome_local_101959002016973032 \
  "https://s.gxrc.com/sJob?schType=1&keyword=python%20%E5%BC%80%E5%8F%91&sortType=1"

# 提取岗位链接（JS eval）
browser-act --session jh eval "JSON.stringify(
  Array.from(document.querySelectorAll('a[href*=\"/jobDetail/\"]')).map(a=>({
    title: a.querySelector('.position-name')?.textContent?.trim()||'',
    salary: a.closest('.position-item')?.querySelector('.salary')?.textContent?.trim()||'',
    company: a.closest('.position-item')?.querySelector('.company-name a')?.textContent?.trim()||'',
    url: a.href
  })).slice(0,10)
)"
```

- `信息化 人工智能 大数据` → 5条
- `环保 治理 咨询` → 2条

## 二、前程无忧 (51job.com) — ✅ 已打通

### 搜索 URL 格式
```
https://we.51job.com/pc/search?keyword=KEYWORD
```

### 提取岗位（JS eval）
```js
Array.from(document.querySelectorAll('.joblist-item')).map(c=>({
  title: c.querySelector('.jname')?.textContent?.trim()||'',
  salary: c.querySelector('.sal')?.textContent?.trim()||'',
  company: c.querySelector('.cname')?.textContent?.trim()||'',
  url: c.querySelector('a')?.href||''
}))
```

### 可行性城市过滤
51job 按城市过滤需要与搜索表单交互（点击城市按钮→选择城市→搜索），URL 参数 `jobArea=CODE` 在 SPA 中不生效。替代方案：
1. **在关键词中包含城市名**：`python开发 南宁`（部分有效，返回较少）
2. **使用完整浏览器交互**：点击城市标签→输入城市→Enter→点搜索按钮
3. **不过滤城市，后期在代码中筛选**：从 `company` 字段的文字中提取城市名

### 已验证搜索关键词
- `环境数据分析` → 15条（大气环境、水质数据、ESG分析师 等）
- `智慧环保` → 15条（智慧水务、智慧水利 等）
- `python开发` → 10条（广州/深圳岗位居多）

## 三、BOSS直聘 (zhipin.com) — ⚠️ 需手动验证

### 问题根因
- IP 被 BOSS 直聘标记为异常访问
- 全浏览器模式和 stealth-extract 均触发验证码
- 移动版 (m.zhipin.com) 同样被拦截

### 解决方案

#### 方案 A：用户手动验证一次（推荐）
```bash
# 1. 用 headed 模式打开，用户看到浏览器窗口
browser-act --session boss browser open chrome_local_101959002016973032 \
  "https://www.zhipin.com/web/geek/job?query=python+%E5%BC%80%E5%8F%91&city=100990500" \
  --headed

# 2. 用户点击验证按钮完成验证（约 5 秒）

# 3. 验证后，cookie 保存在 Chrome 本地 session 中
# 后续可以用同一个 chrome_local 浏览器抓取
browser-act --session boss eval "..."  # 此时不会再有验证码
```

#### 方案 B：用已登录的 Chrome session
如果用户平时就用 Chrome 登录 BOSS 直聘，我们的 `chrome_local_101959002016973032`（即用户的本地 Chrome）已经携带登录 cookie，验证码会显著减少。

#### 方案 C：代理 IP（需要购买）
```bash
browser-act stealth-extract "URL" --dynamic-proxy cn
```

## 四、提取函数参考（Python 封装）

```python
import subprocess, json

def extract_jobs_gxrc(keyword: str, session: str = "jh") -> list[dict]:
    """从广西人才网提取岗位"""
    import urllib.parse
    q = urllib.parse.quote(keyword)
    url = f"https://s.gxrc.com/sJob?schType=1&keyword={q}&sortType=1"
    
    _run(f"--session {session} browser open chrome_local {url}")
    _run(f"--session {session} wait stable --timeout 10000")
    
    js = """JSON.stringify(
      Array.from(document.querySelectorAll('a[href*="/jobDetail/"]')).map(a=>({
        title: a.querySelector('.position-name')?.textContent?.trim()||'',
        salary: a.closest('.position-item')?.querySelector('.salary')?.textContent?.trim()||'',
        company: a.closest('.position-item')?.querySelector('.company-name a')?.textContent?.trim()||'',
        url: a.href
      })).slice(0,20)
    )"""
    
    return json.loads(_run(f"--session {session} eval {shlex.quote(js)}"))

def extract_jobs_51job(keyword: str, session: str = "w51") -> list[dict]:
    """从前程无忧提取岗位"""
    import urllib.parse
    q = urllib.parse.quote(keyword)
    url = f"https://we.51job.com/pc/search?keyword={q}"
    
    _run(f"--session {session} navigate {url}")
    
    js = """JSON.stringify(
      Array.from(document.querySelectorAll('.joblist-item')).map(c=>({
        title: c.querySelector('.jname')?.textContent?.trim()||'',
        salary: c.querySelector('.sal')?.textContent?.trim()||'',
        company: c.querySelector('.cname')?.textContent?.trim()||'',
        url: c.querySelector('a')?.href||''
      })).slice(0,20)
    )"""
    
    return json.loads(_run(f"--session {session} eval {shlex.quote(js)}"))
```
